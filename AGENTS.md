# Antigravity Guidelines & Rules

## Git Push Policy
- **STRICT PROHIBITION**: Do NOT run `git push` under any circumstances.
- **Allowed Actions**: You may inspect git status, stage files (`git add`), and create local commits (`git commit`).
- **Notification**: When changes are committed, inform the user and provide the exact command (e.g., `git push origin main` or `git push origin gh-pages`) so the user can execute the push themselves, because the user manages multiple Git accounts.
